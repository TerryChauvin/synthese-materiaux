# Chemist's guide: reading a sheet and querying the database

Figures as of 17 October 2026 (`synthese.db`, read-only SELECT queries). Method: [methodology.md](methodology.md). What not to trust without checking: [limits_and_warnings.md](limits_and_warnings.md). Note: sheets (`fiches/`) and annotations are written in French.

## 1. Reading a sheet

Each paper has a sheet `fiches/<PMCID>.md` (270 sheets), generated by `python3 -I fiche.py <PMCID>`. Short, clean example: `fiches/PMC6199062.md`. Layout:

1. **Before reproducing ("Avant de refaire")**: reproducibility limits and safety notes. Read first.
2. **Summary, aim, why these data, branch comparison, observed trend**: interpretations, kept apart from the data.
3. **One section per route**: material, method, completeness, yield, reagent table, numbered steps with parameters, each followed by the paper's quote.

Reading rule: **the quote is the proof.** If a value and its quote disagree, trust the quote and report it.

## 2. Vocabulary

| Term | Meaning |
|---|---|
| **`not_stated`** (shown as **non cité**) | Information looked for and absent from the paper (or only implicit). Not zero, not a default: you must determine it. Table `not_stated` (15,214 rows) lists missing reagents, steps or quantities per route (`scope` = `reagent`, `step` or `route`). |
| **Base route / branch** | A base route is the full protocol. A branch (`parent_route_id` not null) records only what it changes relative to its parent: temperature, time, reagent, ratio… `route_variations` gives the branch value and the parent value. Parameters not redefined are the parent's (`overridden_by_branch` column of `v_route_complete`). |
| **Doubt** (`doubts`) | Ambiguity met during extraction (doubtful unit, table row attribution…). All have a written resolution except those with status `open` (14 on 2026-10-17). |
| **`limite_reproductibilite`** | Annotation: what a chemist must know before reproducing (gap, inconsistency of the paper, missing supplementary file, precaution). It describes a limit; it never corrects a value. 2,399 in total. |
| **`from_figure`** | Value read off a figure, not written in the text. The quote is then the figure caption and `from_figure` gives the panel ("Fig. 3b"). Approximate reading (2 significant figures at most). On 2026-10-17: 3,416 outcomes, 158 variations and 35 parameters are flagged this way (the column is empty for values written in the text). |
| **`succeeded = 0`** | Failed attempt or target not obtained, kept on purpose. |
| **Completeness** | Score 0–1 of how much the route lets you reproduce. Low score ≠ error: the paper is incomplete. |
| **Plausibility verdict** | Science critique's judgement per route: `coherente`, `douteuse`, `incoherente`, `inverifiable`. "douteuse" mostly means reservations (missing information, multi-variable control). Mechanisms (`mecanisme_analyse`) are **hypotheses**, not results. |

Annotation types: `limite_reproductibilite`, `tendance_observee`, `mecanisme_analyse`, `mecanisme_auteurs`, `securite_analyse`, `securite_auteurs`, `comparaison_branches`, `pourquoi_ces_donnees`, `resume`, `objectif_etude`, `conclusion_auteurs`.

## 3. Five tested SQL queries

The database is a SQLite file: DB Browser for SQLite, DBeaver, or Python (`sqlite3.connect("file:synthese.db?mode=ro", uri=True)`). These queries were run on 2026-10-17 on `PMC6199062` (hydrothermal Sb2S3, 120/150/180 °C).

**1. Full protocol of a branch, with quotes.**

```sql
SELECT step_order, action, parameter, value_num, value_text, unit, quote
FROM v_route_complete
WHERE pmcid = 'PMC6199062' AND branch_label = 'Sb2S3-150'
ORDER BY step_order;
```
Result: step 1 `dissolve` 15 min, step 3 `heat` 150 °C and 12 h, step 4 `wash`… each with its quote.

**2. Effect of a variation on the outcome.**

```sql
SELECT branch_label, parent_label, branch_value, variation_unit, parent_value,
       property, outcome_value
FROM v_comparaison
WHERE pmcid = 'PMC6199062' AND parameter = 'temperature'
ORDER BY branch_label;
```
Example row: `Sb2S3-120` vs `Sb2S3-150`, 120 °C vs 150 °C, phase "orthorhombic Sb2S3 phase and monoclinic Sb8O11Cl2 phase", nanowires 80–100 nm.

**3. What the paper does not say.**

```sql
SELECT r.branch_label, n.scope, n.step_order, n.reagent, n.name
FROM not_stated n
JOIN synthesis_routes r ON r.id = n.route_id
JOIN papers p ON p.id = r.paper_id
WHERE p.pmcid = 'PMC6199062' AND n.status = 'non_cite';
```
For route `Electrode_Sb2S3`: yield, current collector, coating method, drying, electrode area.

**4. What to know before reproducing.**

```sql
SELECT r.branch_label, a.text
FROM annotations a
JOIN papers p ON p.id = a.paper_id
LEFT JOIN synthesis_routes r ON r.id = a.route_id
WHERE p.pmcid = 'PMC6199062' AND a.type = 'limite_reproductibilite';
```
Empty `branch_label` = limit applies to the whole paper.

**5. Values read off figures (use with care), or well-documented routes of one method.**

```sql
SELECT p.pmcid, r.branch_label, o.property, o.value_num, o.unit, o.from_figure
FROM outcomes o
JOIN synthesis_routes r ON r.id = o.route_id
JOIN papers p ON p.id = r.paper_id
WHERE o.from_figure IS NOT NULL;
-- from_figure holds the panel ("Fig. 3b")
```
Variant to find nearly complete hydrothermal routes:
```sql
SELECT p.pmcid, r.branch_label, ROUND(r.completeness_score, 2) AS completeness
FROM synthesis_routes r JOIN papers p ON p.id = r.paper_id
WHERE r.parent_route_id IS NULL AND r.completeness_score >= 0.9
  AND r.method LIKE '%hydrothermal%';
```

## 4. Reading `compare.py`

`python3 -I compare.py "ZnO"` lists the **base routes** whose material (name or formula) contains the requested whole word: 31 base routes for "ZnO" on 2026-10-17. For each: publication, label, number of branches, material and phase, `méthode` (method), `conditions` (temperature, time, pH, atmosphere per step, as `step:parameter=value`) and `résultats` (property=value). Use: compare the conditions different groups use for one material and spot a value far from the others. Caveats: case matters for a formula ("Ag" matches neither "fragment" nor "AgCl"), and two papers are comparable only if their scales and measured quantities are; read the quote before concluding.
