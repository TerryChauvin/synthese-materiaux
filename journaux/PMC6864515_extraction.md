# Journal d'extraction PMC6864515 (CsPbX3 dans nanofibres PMMA/TPU par filage électro-microfluidique)

- Voie de base = `CsPbBr3/PMMA/TPU` : seul protocole décrit en entier (trois solutions Cs/Pb/PMMA, Br−/PMMA, TPU/DMF, puis filage coaxial, séchage 70 °C). Les trois solutions précurseurs sont des étapes de cette voie, pas des voies `intermediate` : elles ne sont jamais isolées ni réutilisées ailleurs.
- 7 branches halogénures (Cl : X = 0, 0,3, 0,7 ; I : X = 0, 0,3, 0,5, 0,7), rangées de Table 1 attribuées par la ligne d'en-tête « CsPb(BrxCl1− x)3 » ou « CsPb(BrxI1− x)3 » qui précède (le tableau ne répète pas la série dans chaque rangée). Contrôle : X = 0,3 Cl = 485 nm et X = 0,3 I = 616 nm concordent avec le texte (Fig. 3a,c).
- Variations des branches : `halide_source` (parent_value none, additif absent du parent) + `halide_ratio_x`. D'où 14 avertissements « paramètre inconnu du protocole hérité », attendus (convention RUNBOOK pour les additifs). Quantité de sel ajouté non citée (`not_stated: amount`) ; l'article dit seulement que les concentrations changent.
- Héritage des étapes accepté pour les branches : l'article ne dit pas « same procedure » mais décrit l'ajout de C32H68ClN/C32H68IN à la solution Br−/PMMA pour le même procédé FSC ; consigné en doute. Pas de remplacement du TOAB déclaré par l'article, donc non extrait (cas X = 0 incohérent, voir doute).
- X = 0 (Cl) : 460 nm et diamètre 253 ± 60 nm, identique à CsPbBr3 ; recopié littéralement, doute sur l'identité du matériau.
- Contradictions : 524 nm (Table 1) contre 525 nm (texte, Fig. 3b) pour CsPbBr3/PMMA/TPU, tableau retenu ; FWHM de CsPb(Br0.3Cl0.7)3 « 19 nm » au texte contre 21 nm au tableau (19 nm est la valeur de X = 0), tableau retenu ; « barium acetate (C2H3CsO2) » extrait comme acétate de césium, nom de l'article gardé dans `name`.
- PNCs purs : voie de base à part (pas de filage, précipitation à température ambiante). Les quantités et le chauffage 150 °C sont repris par le renvoi explicite « as described above ... except no PMMA » ; les agitations de 48 h (dissolution du PMMA) ne sont pas reprises, durée d'agitation Cs/Pb non citée.
- Film pur CsPbBr3 à la tournette : voie `device` à part (une phrase, aucun paramètre) ; porte les résultats de comparaison (Table S1 : τ, B ; angle de contact 77,95° ; stabilité).
- Table S1 de l'annexe est éclatée une valeur par ligne : lue dans l'ordre de l'en-tête (τ1, B1, τ2, B2) et recoupée avec les valeurs du texte principal (10,8 % ; 45,22 % ; 0,54 ; 5,15 ; 21,74 ; 20,02 ns).
- Dispositifs : LED cœur (Br0.3I0.7) et étoile (Br0.3Cl0.7) attribuées selon l'ordre de « respectively » ; bracelet (Br0.5I0.5) à part. Films réutilisés en rôle `intermediate`.

Fig. S4 (teneur en CsPbBr3), S5 (diamètre des fibres), S6, S1–S3 : images d'annexe absentes du dépôt, aucune branche créée (pas de valeurs) ; annotation « Annexe absente du dépôt » et trois échantillons du `sample_inventory` sans voie.
