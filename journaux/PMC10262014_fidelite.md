# Journal de la critique de fidélité, PMC10262014

- Ma liste d'échantillons avant ouverture de l'extraction : 10 (sans IL ; 0,5, 1,0 et 2,5 % v/v de chacun des trois liquides ioniques). Elle coïncide avec `sample_inventory` ; les deux lignes `route: null` (plage 0,1–2,5 %, tables S1/S2 par IL) sont justifiées : l'article ne donne aucune concentration pour ces mesures.
- Constat `sure` unique : l'ajout goutte à goutte de l'IL (« The calculated volume of IL was added dropwise… ») n'existe dans aucune des 9 branches, ni comme étape ni comme paramètre ; l'extracteur l'avait seulement mis dans la description de l'étape 3 du parent, qui ne concerne pas ces branches. Le texte est sans ambiguïté sur l'ordre NaOH → IL → agitation.
- Constat `deduit` (probable) sur ZnO_noIL : le protocole n'est écrit que pour la synthèse avec IL ; transposition déjà déclarée en doute par l'extracteur, je ne la considère pas comme une erreur mais comme un état à marquer.
- SAED de [C4mim]CH3SO4 : le texte dit « 0.5% and 1.0% », la légende de Fig. 3 ne contient que 0,5 % (d) et 2,5 % (e) ; probable coquille. J'ai noté `attribution` probable plutôt que `faux` car la citation littérale soutient bien la valeur actuelle.
- Valeurs `from_figure` : Fig. 1d lue à l'image, C2mim 2,5 % ≈ 860 nm, C4mim 0,5 % ≈ 410 nm, C4mim 1,0 % ≈ 735 nm, C4mim 2,5 % ≈ 528 nm ; tout est dans ± 20 nm, donc pas de constat de valeur. Seule la phrase « decreased » pour C4mim 0,5 % (410 nm > 400 nm du témoin) est signalée en mineur.
- Insets de Fig. 3 : 0,21 nm (b), 0,55 nm (c), 0,62 nm (d), 0,18 nm (e), 0,75 nm (f), 1,01 nm (g) ; le texte donne 0,25 / 0,5 / 0,50 / 0,25 / 0,75 / 1,0. Écarts de 24 % et 28 % en (d) et (e). Les valeurs extraites sont celles du texte (la citation fait foi) ; je demande une annotation, pas une correction.
- Fig. 5B (image) contredit le texte : « Large petal » pour 2,5 % de [C4mim]CH3SO4 (texte : flakes) et « Intersecting sheets » pour 1,0 % de [C2mim]C2H5SO4 (texte : aiguilles). Mineur, pour annotation seulement.
- Écarté : le texte dit que 596 nm est un « maximum » alors que la Fig. 1d montre ≈ 860 nm à 2,5 % de [C2mim]CH3SO4 ; l'extraction n'a pas repris le mot « maximum » (annotation `tendance_observee` parle d'extremum), donc ce n'est pas une erreur d'extraction, seulement une limite de reproductibilité (listée).
- Écarté : mode d'agitation magnétique, vu seulement sur l'image t1 (équation Zn(OH)4 2− → ZnO) ; pas de phrase du texte, donc pas un constat `non_cite_a_tort` ; mis dans les manques de reproductibilité.
- Écarté : `method_sources` vide. Les renvois [[cit…]] ne portent que l'introduction, JCPDS (cit61) et le modèle Kubelka-Munk, exclus par la règle du 2026-10-13.
- Écarté : appariement Table S1. Le PDF extrait liste gabarits et valeurs en blocs séparés ; l'ordre (C2mim CH3SO4, C2mim C2H5SO4, C4mim CH3SO4) est cohérent avec « 29 à 23 nm » du texte, mais invérifiable sur image ; le Table S2 est confirmé par la Fig. 2b. Aucun constat, mentionné dans les notes.
- Cases `not_stated` vérifiées (19) : rendement, supplier de l'eau, température/durée/vitesse (étape 1), débit d'addition, vitesse d'agitation, vitesses de chauffe/refroidissement, taux de remplissage, pression, pureté des IL : toutes correctes.
